# 📚 Book Store Website

A responsive and interactive Book Store website built from scratch using **HTML, CSS, and Vanilla JavaScript**. The website features a modern design that allows users to explore featured books, browse new arrivals, discover special deals, and read customer testimonials.

## 🚀 Features

- Responsive double header with search form.
- Sticky bottom navigation bar using JavaScript.
- Home section with a book shelf slider.
- Responsive icons section using CSS Grid.
- Featured books section with Swiper.js slider.
- Newsletter section with parallax background.
- New arrivals section with touch slider.
- Deals section using CSS Flexbox.
- Customer testimonials section with touch slider.
- Blog and news section with responsive cards.
- Responsive footer using CSS Grid.
- Mobile-friendly design for different screen sizes.

## 🛠️ Tech Stack

- **HTML5** – Website structure.
- **CSS3** – Styling, layouts, animations, and responsiveness.
- **JavaScript** – Interactive functionality.
- **Swiper.js** – Touch-enabled sliders and carousels.

## ⚙️ How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.

## 🎯 Project Objective

The objective of this project is to develop a responsive book store website while practicing HTML, CSS, JavaScript, responsive web design, CSS Grid, Flexbox, and Swiper.js.
